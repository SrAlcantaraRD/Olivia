# Testing (current)

The repo uses Jest for unit tests and Detox for E2E.

- Jest entry: `pnpm test`
- E2E scripts: `pnpm e2e:test:*`

Reference docs:

- [TESTING.md](../TESTING.md)
- Test folders: `tests/unit-test`, `tests/integration`, `tests/e2e`

Note: Auth E2E flows exist as a folder (`tests/e2e/auth/`).
