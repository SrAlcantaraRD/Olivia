# Navigation Abstraction Implementation Guide

## Overview
Implement a navigation abstraction layer in Oliva App to remove direct usage of `router.push` from UI components and screens. All navigation must be handled through hooks that orchestrate use-cases and adapters, ensuring the domain layer remains technology-agnostic and following Clean Architecture principles. This refactoring improves testability, maintainability, and separation of concerns by treating navigation as an infrastructure concern abstracted via ports and adapters.

## Implementation Strategy
High-level approach following Clean Architecture:
- Domain layer: Define a NavigationPort as an abstraction for routing operations.
- Database layer: Not applicable (navigation is not data persistence).
- Hooks layer: Create a hook that injects the navigation adapter and provides typed navigation methods.
- UI layer: Update components to use the navigation hook instead of direct router calls.
- App layer: Refactor screens to consume navigation via hooks, ensuring no direct router.push.
